# v0.6.1 · 文档修正

[English](release-v0.6.1.en.md) · **中文**

无代码改动。0.6.0 发布后核对发现两个 README 描述的还是改版**之前**的界面。

## 改了什么

| 位置 | 原来写的 | 实际行为 |
|---|---|---|
| 类型筛选 | 「点中一个后下方浮出第二行」 | 三行平铺：一级 / 细分 / 已选 |
| 「已删除」 | 「同一行的 chip」 | 排在类型行**末尾** |
| 清除筛选 | 「chip 右边出现细分隔线」 | 第三行**末尾** |
| 测试总账 | 173 项 | 187 项 |

另外补了四条此前文档完全没提的行为：

- **同家族的一级与二级互斥**：勾「代码」清掉 `code/*`，勾 `code/java` 取消「代码」。
- **多选是并集**：勾两个一级同时列出两类文件，不是交集。
- **两列 grid 对齐**：标签独占一列，芯片在第二列内部换行，所以换行后每行左边界仍对齐。
- **扩展名 8+N 折叠**：超过 8 个折成计数，点开可就地展开、可再收起；已勾选的永远置顶。

还有两处容易被误解的细节写进了文档：「已删除」是**视图开关**而非类型，开关状态只看自己、
不看计数（开启但当前类型下无匹配时显示 0 并保持高亮）；「清除筛选」在只开「已删除」时也会
出现——那是唯一能关掉该开关的入口。
